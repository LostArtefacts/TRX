## Assault course module

Module for controlling the gym assault course timer.

### Functions

- [lua]`trx.assault.start()`  
    Starts the assault course timer and resets the current course time.

- [lua]`trx.assault.stop()`  
    Stops the assault course timer while keeping the timer visible.

- [lua]`trx.assault.reset()`  
    Stops and hides the assault course timer, clearing its runtime state.

- [lua]`trx.assault.quad.start()`  
    Starts the TR3 quad race track timer and resets the current course time.

- [lua]`trx.assault.quad.stop()`  
    Stops the TR3 quad race track timer while keeping the timer visible.

- [lua]`trx.assault.quad.reset()`  
    Stops and hides the TR3 quad race track timer, clearing its runtime state.
